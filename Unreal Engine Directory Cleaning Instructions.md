# Unreal Engine Directory Cleaning Instructions

This guide outlines which folders inside an Unreal Engine project directory are safe to delete to clear cache or fix build issues, and which folders must remain untouched to prevent data loss.

---

## 🟢 Folders SAFE to Delete

The engine automatically regenerates these folders the next time you open, package, or compile the project.

* **`Intermediate/`**
  * **What it does:** Holds temporary build data, shader caches, and compiler intermediates.
  * **Why delete:** Deleting this fixes many weird editor or cooking bugs and frees up massive amounts of storage space.
  * *Note: Your next project startup or shader compilation will take longer.*
* **`DerivedDataCache/` (DDC)**
  * **What it does:** Stores cached assets, textures, and compiled shaders for rapid loading.
  * **Why delete:** Reclaims gigabytes of disk space; the engine will rebuild the cache as needed.
* **`Binaries/`**
  * **What it does:** Contains compiled executable files and DLLs (primarily for C++ projects).
  * **Why delete:** Safely forces a fresh rebuild of your game modules when you compile.
* **`Build/`**
  * **What it does:** Contains pre-built, platform-specific config assets.
  * *Warning: Do NOT delete this if you are developing for Android and it contains your custom keystore file.*
* **`.vs/`**
  * **What it does:** Secret workspace folder used by Visual Studio.
* **`*.sln` or `*.xcworkspace`**
  * **What it does:** Solution files for C++ IDEs.
  * **Why delete:** Can easily be regenerated by right-clicking your `.uproject` file and selecting **Generate Visual Studio project files**.
* **`Plugins/<PluginName>/Intermediate/` and `Plugins/<PluginName>/Binaries/`**
  * **What it does:** Build intermediates and compiled DLLs for a C++ plugin.
  * **Why delete:** Regenerated when the project is compiled. Delete only these two subfolders, never the plugin folder itself (see `Plugins/` below).
  * *Note: The editor cannot load the plugin until the project is rebuilt.*

---

## 🔴 Folders You Must NEVER Delete

Deleting these folders will permanently delete your work or corrupt your project structure.

* **`Content/`**
  * **Danger:** Contains all project assets, levels, blueprints, materials, textures, and audio. Deleting this destroys your game.
* **`Config/`**
  * **Danger:** Stores your active project settings, input mappings, and collision settings.
* **`Source/`**
  * **Danger:** Contains your primary C++ source code files (`.cpp` and `.h`).
* **`Plugins/`**
  * **Danger:** Houses custom or marketplace plugins essential to your project.
* **The `*.uproject` file**
  * **Danger:** The main project descriptor file needed to open the project.

---

## ⚠️ The `Saved/` Folder (Proceed with Caution)

* **What it does:** Stores logs, crash reports, screenshots, and local project configuration overrides.
* **Can you delete it?** Mechanically yes, but it is generally **not recommended**. It contains your local **Autosaves** and **Backup** folders. If a blueprint or map becomes corrupted, this folder is your only fallback for local recovery.

---

## 🌐 Global System Caches (Safe to Delete)

To free up additional room on your primary operating system drive, you can wipe the temporary files inside:

* `C:\Users\<YourName>\AppData\Local\UnrealEngine\`
* `C:\Users\<YourName>\AppData\Local\UnrealEditorFortnite\Saved\` *(for UEFN developers)*
