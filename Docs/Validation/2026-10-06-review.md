## Code findings

| # | Severity | Finding | Status |
|---|---|---|---|
| 1 | Medium | Approved material replacement called `UStaticMesh::SetMaterial` per slot. In 5.8 each call opens its own transaction and runs `PreEditChange`/`PostEditChangeProperty` (engine `StaticMesh.cpp`), so a mesh was rebuilt once per replaced slot. | Fixed in `ConVerseImportProcessing.cpp`: slots are edited directly, with one `Modify`/`PreEditChange`/`PostEditChangeProperty` per changed mesh. |
| 2 | Medium | Component material replacement in the same pass did not call `Modify()`. | Fixed: one `Modify()` per changed component. |
| 3 | Medium | `UConVerseStaticMeshConsolidationLibrary` could show the dedupe confirmation dialog during unattended runs or editor scripts. | Fixed: also requires `!FApp::IsUnattended()` and `!GIsRunningUnattendedScript`. The Dataprep operation calls the utilities directly and never showed the dialog. |
| 4 | Low | Texture and sidecar paths from the source are made absolute with `FPaths::ConvertRelativePathToFull` without a containment check. | No change. `ConvertRelativePathToFull` already collapses `..`; the paths are only read and hashed; textures legitimately live outside the source folder. Containment would be a product decision. |
| 5 | Low | The import panel's `OnFinishedChangingProperties` lambda captured raw `this`. | Fixed: bound with `AddSPLambda`. |
| 6 | Low | Linear lookups inside loops (material slots in the service, groups in the manifest lookup). | Not changed; not checked by profiling. |

## Claims rejected after checking

- Deprecated `CreateHISMsFromSelection` lacked `DeprecatedFunction` meta: it already has it.
- Reimport handler not unregistered at shutdown: the `FReimportHandler` base registers and unregisters itself.
- Dataprep consolidation shows a dialog: it does not call the library function.
- `Modify()` missing before `UStaticMesh::SetMaterial`: the engine handles it; the real issue is finding 1.
- Unregistered ISM component at `ConVerseHISMUtils.cpp:1300`: the line does not exist.
- Unsafe DataTable row casts and int64 overflow in manifest indexing: guarded or unrealistic.
- Test count mismatch: 55 tests are defined, 53 in the suite plus 2 separately invoked interruption fixtures.
